# tool

Agent 可调用工具，统一经过注册、策略、审批和副作用边界。

## 边界

本说明只描述当前保留的能力。生成产物、运行数据和已删除模块不属于本目录契约。

## 子目录

- `api/`：工具 SPI、注册表、执行上下文和内建工具装配。
- `filesystem/`：工作区内的读写、编辑、目录浏览和 Diff Review 工具。
- `pack/`：核心工具包定义；已删除能力不会在这里被重新注册。
- `process/`：受审批与执行后端约束的命令执行工具。
- `search/`：本地 Glob/Grep 搜索工具，不访问互联网。
