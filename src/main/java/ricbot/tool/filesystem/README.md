# filesystem

工作区内的读写、编辑、目录浏览和 Diff Review 工具。

## 边界

本说明只描述当前保留的能力。生成产物、运行数据和已删除模块不属于本目录契约。

## 子目录

无直接子目录。

## 直接文件

- `DiffReview.java`：Diff Review：本包内的领域类型或协作组件。
- `DiffReviewService.java`：Diff Review Service：封装该领域用例或业务规则。
- `EditFileTool.java`：Edit File Tool：工具协议、实现或注册逻辑。
- `FileReadState.java`：File Read State：执行结果、报告或状态值对象。
- `FileToolSupport.java`：File Tool Support：工具协议、实现或注册逻辑。
- `FsTool.java`：Fs Tool：工具协议、实现或注册逻辑。
- `ListDirTool.java`：List Dir Tool：工具协议、实现或注册逻辑。
- `ReadFileTool.java`：Read File Tool：工具协议、实现或注册逻辑。
- `WriteFileTool.java`：Write File Tool：工具协议、实现或注册逻辑。
