# ricbot

Ricbot 根包，按入口、应用编排、领域、基础设施、外部集成和工具分层。

## 边界

本说明只描述当前保留的能力。生成产物、运行数据和已删除模块不属于本目录契约。

## 子目录

- `app/`：进程入口与依赖装配层；不承载核心业务规则。
- `application/`：应用服务层，把 CLI 用例编排到领域对象，避免入口直接操纵存储。
- `domain/`：核心领域模型；不依赖 CLI、HTTP Server 或界面实现。
- `infra/`：文件系统、配置、执行后端、持久化、遥测和模板等技术实现。
- `integration/`：外部系统适配层；当前只包含 CLI 命令适配与模型 Provider。
- `tool/`：Agent 可调用工具，统一经过注册、策略、审批和副作用边界。
