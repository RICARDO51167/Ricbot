# infra

文件系统、配置、执行后端、持久化、遥测和模板等技术实现。

## 边界

本说明只描述当前保留的能力。生成产物、运行数据和已删除模块不属于本目录契约。

## 子目录

- `common/`：通用 JSON、哈希、路径和轻量基础组件。
- `config/`：配置文件读取、环境变量替换、旧配置拒绝和运行路径解析。
- `execution/`：Local/Docker 执行后端与隔离策略；Docker 默认断网且禁止静默回退。
- `fs/`：受工作区边界约束的文件系统辅助实现。
- `persistence/`：共享 CAS 状态、不可变产物和文件持久化实现。
- `runtime/`：进程生命周期辅助能力。
- `security/`：本地密钥与敏感信息处理实现。
- `telemetry/`：可选 OpenTelemetry 投影；失败不能影响 Run 提交。
- `template/`：系统提示模板加载与工具提示格式化。
