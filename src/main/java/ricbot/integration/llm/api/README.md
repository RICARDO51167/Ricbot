# api

Provider 公共 SPI、消息、工具调用和多部分请求模型。

## 边界

本说明只描述当前保留的能力。生成产物、运行数据和已删除模块不属于本目录契约。

## 子目录

无直接子目录。

## 直接文件

- `GenerationSettings.java`：Generation Settings：本包内的领域类型或协作组件。
- `LLMProvider.java`：LLMProvider：模型 Provider 的出站调用或能力描述。
- `LLMResponse.java`：LLMResponse：本包内的领域类型或协作组件。
- `MultipartBodyBuilder.java`：Multipart Body Builder：本包内的领域类型或协作组件。
- `OpenAIResponsesSupport.java`：Open AIResponses Support：本包内的领域类型或协作组件。
- `ToolCallRequest.java`：Tool Call Request：工具协议、实现或注册逻辑。
