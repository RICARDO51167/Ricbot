# trace

只读 Trace 投影、检索和导出；不作为运行事实源。

## 边界

本说明只描述当前保留的能力。生成产物、运行数据和已删除模块不属于本目录契约。

## 子目录

无直接子目录。

## 直接文件

- `TraceEvent.java`：Trace Event：事件、消息或审计事实模型。
- `TraceEventType.java`：Trace Event Type：事件、消息或审计事实模型。
- `TraceRecorder.java`：Trace Recorder：事件、消息或审计事实模型。
- `TraceRenderer.java`：Trace Renderer：事件、消息或审计事实模型。
- `TraceStore.java`：Trace Store：负责状态持久化、读取或查询。
- `TraceTimeline.java`：Trace Timeline：事件、消息或审计事实模型。
- `TraceTimelineEvent.java`：Trace Timeline Event：事件、消息或审计事实模型。
- `TraceTimelineSeverity.java`：Trace Timeline Severity：事件、消息或审计事实模型。
- `TraceTimelineSource.java`：Trace Timeline Source：事件、消息或审计事实模型。
- `TraceViewerService.java`：Trace Viewer Service：封装该领域用例或业务规则。
