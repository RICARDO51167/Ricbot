# message

CLI 入站/出站消息与进程内 MessageBus；这是内部事件机制，不是网络 Channel。

## 边界

本说明只描述当前保留的能力。生成产物、运行数据和已删除模块不属于本目录契约。

## 子目录

无直接子目录。

## 直接文件

- `InboundMessage.java`：Inbound Message：事件、消息或审计事实模型。
- `InboundMessages.java`：Inbound Messages：事件、消息或审计事实模型。
- `MessageBus.java`：Message Bus：事件、消息或审计事实模型。
- `OutboundMessage.java`：Outbound Message：事件、消息或审计事实模型。
- `OutboundMessages.java`：Outbound Messages：事件、消息或审计事实模型。
