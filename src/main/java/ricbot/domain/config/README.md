# config

配置诊断、有效配置报告和迁移提示模型。

## 边界

本说明只描述当前保留的能力。生成产物、运行数据和已删除模块不属于本目录契约。

## 子目录

无直接子目录。

## 直接文件

- `ConfigDoctorReport.java`：Config Doctor Report：声明配置、选项或不可变执行规格。
- `ConfigDoctorService.java`：Config Doctor Service：封装该领域用例或业务规则。
- `ModelCapability.java`：Model Capability：本包内的领域类型或协作组件。
- `ProviderCapability.java`：Provider Capability：模型 Provider 的出站调用或能力描述。
- `ProviderCapabilityResolver.java`：Provider Capability Resolver：模型 Provider 的出站调用或能力描述。
