# policy

角色、工具和命令策略，决定允许、拒绝或要求审批。

## 边界

本说明只描述当前保留的能力。生成产物、运行数据和已删除模块不属于本目录契约。

## 子目录

无直接子目录。

## 直接文件

- `PolicyAwareToolExecutor.java`：Policy Aware Tool Executor：工具协议、实现或注册逻辑。
- `PolicyDecision.java`：Policy Decision：本包内的领域类型或协作组件。
- `PolicyDecisionType.java`：Policy Decision Type：本包内的领域类型或协作组件。
- `PolicyEngine.java`：Policy Engine：驱动对应执行生命周期。
- `PolicyRenderer.java`：Policy Renderer：本包内的领域类型或协作组件。
- `PolicyRule.java`：Policy Rule：本包内的领域类型或协作组件。
- `PolicyViolation.java`：Policy Violation：本包内的领域类型或协作组件。
- `RoleToolPolicy.java`：Role Tool Policy：工具协议、实现或注册逻辑。
