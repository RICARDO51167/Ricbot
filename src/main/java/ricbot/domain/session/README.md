# session

对话 Session 模型、管理与持久化契约。

## 边界

本说明只描述当前保留的能力。生成产物、运行数据和已删除模块不属于本目录契约。

## 子目录

无直接子目录。

## 直接文件

- `Session.java`：Session：本包内的领域类型或协作组件。
- `SessionManager.java`：Session Manager：本包内的领域类型或协作组件。
- `SessionMessage.java`：Session Message：事件、消息或审计事实模型。
- `SharedSessionManager.java`：Shared Session Manager：本包内的领域类型或协作组件。
