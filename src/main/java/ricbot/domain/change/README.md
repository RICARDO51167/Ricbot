# change

Git ChangeSet 的审阅、批准、提交与回滚边界。

## 边界

本说明只描述当前保留的能力。生成产物、运行数据和已删除模块不属于本目录契约。

## 子目录

无直接子目录。

## 直接文件

- `ChangeSetRenderer.java`：Change Set Renderer：本包内的领域类型或协作组件。
- `ChangeSetService.java`：Change Set Service：封装该领域用例或业务规则。
- `GitChangeSet.java`：Git Change Set：本包内的领域类型或协作组件。
- `GitChangeSetStatus.java`：Git Change Set Status：执行结果、报告或状态值对象。
- `PendingChangeAction.java`：Pending Change Action：本包内的领域类型或协作组件。
