# ricbot

Ricbot 测试根包，覆盖架构边界、领域、基础设施、集成和工具。

## 边界

本说明只描述当前保留的能力。生成产物、运行数据和已删除模块不属于本目录契约。

## 子目录

- `app/`：进程入口、脚本与打包资源测试。
- `architecture/`：防止已删除模块回流并约束依赖方向的架构测试。
- `domain/`：核心领域测试集合。
- `infra/`：基础设施实现测试集合。
- `integration/`：外部 Provider 适配测试集合；本地 HttpServer 仅作为出站请求的测试替身。
- `tool/`：工具注册、文件和进程工具测试集合。
