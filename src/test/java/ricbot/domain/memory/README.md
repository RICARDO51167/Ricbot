# memory

对应生产包 `memory` 的自动化测试，验证正常路径、失败边界和持久化不变量。

## 边界

本说明只描述当前保留的能力。生成产物、运行数据和已删除模块不属于本目录契约。

## 子目录

无直接子目录。

## 直接文件

- `MemoryStoreStructuredTest.java`：验证 Memory Store Structured Test 的行为与边界。
- `MemoryWritePolicyTest.java`：验证 Memory Write Policy Test 的行为与边界。
- `TenantMemoryServiceTest.java`：验证 Tenant Memory Service Test 的行为与边界。
