# trace

## 边界

本说明只描述当前保留的能力。生成产物、运行数据和已删除模块不属于本目录契约。

## 子目录

- `TraceRendererTest.java`：验证 Trace Renderer Test 的行为与边界。
- `TraceStoreTest.java`：验证 Trace Store Test 的行为与边界。
- `TraceViewerServiceTest.java`：验证 Trace Viewer Service Test 的行为与边界。
